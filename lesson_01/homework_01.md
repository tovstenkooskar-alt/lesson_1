### 1. Разбор действий в YouTube

**Действие 1: Постановка лайка под видео**
* **Что уходит на сервер:** Идентификатор пользователя (токен авторизации), ID видеоролика, тип действия (поставить лайк).
* **Что проверяет сервер:** Авторизован ли пользователь, существует ли такое видео, не стоит ли уже лайк от этого аккаунта.
* **Куда сохраняется:** В базу данных взаимодействий пользователей. Также инкрементируется счетчик лайков конкретного видео (обычно в кэше для быстрого доступа).
* **Что возвращается:** Статус успешного выполнения и актуальное количество лайков для обновления интерфейса.

**Действие 2: Публикация комментария**
* **Что уходит:** Текст комментария, ID видео, токен пользователя.
* **Что проверяет:** Валидность токена, длину текста не пустой ли он, а также прогоняет текст через антиспам-системы и фильтры цензуры.
* **Куда сохраняется:** В базу данных комментариев с привязкой к ID видео и ID автора.
* **Что возвращается:** Данные созданного комментария его ID, дата создания, чтобы приложение сразу отрисовало его в ленте под видео.

**Действие 3: Поиск видеоролика**
* **Что уходит:** Строка с поисковым запросом, параметры фильтрации (например, "за эту неделю"), данные о локали пользователя.
* **Что проверяет:** Корректность запроса. Сервер обращается к поисковому индексу и алгоритмам рекомендаций, чтобы ранжировать выдачу под конкретного пользователя.
* **Куда сохраняется:** Сам запрос сохраняется в историю поиска аккаунта.
* **Что возвращается:** Список объектов (названия видео, ссылки на превью, названия каналов, продолжительность), которые приложение выводит в виде списка результатов.

### 2. Место для отказа: Публикация комментария

**Сценарий:** Пропадание сети во время отправки комментария.
**Как ведет себя приложение на самом деле:** Если написать комментарий и в момент нажатия на кнопку отправить отключить интернет, приложение не падает. Сначала может появиться индикатор загрузки, а затем всплывающее уведомление об ошибке подключения. Сам набранный текст при этом не стирается из поля ввода, давая возможность повторить отправку после восстановления связи. 
Если при медленном интернете нажать кнопку отправить дважды, дублирования комментария не происходит — приложение блокирует кнопку после первого нажатия до получения ответа от бэкенда.
